# groundstation-console

[![ci](https://github.com/maisymylod/groundstation-console/actions/workflows/ci.yml/badge.svg)](https://github.com/maisymylod/groundstation-console/actions/workflows/ci.yml)
[![bazel](https://github.com/maisymylod/groundstation-console/actions/workflows/bazel.yml/badge.svg)](https://github.com/maisymylod/groundstation-console/actions/workflows/bazel.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

The **operator console** of the Heliosnet ground system: a production-grade ops
view over the suite's telemetry and incident data. A Go backend owns telemetry and
incident state and serves an HTTP/JSON API, fed live off a Kafka/Redpanda topic;
an Angular SPA renders the fleet, per-satellite telemetry, and the incident feed
from that API. It runs from a clean clone with one command against a bundled,
deterministic fixture, and switches to live telemetry when a broker is configured.

## Quickstart

```bash
make run          # build + run the backend on the bundled fixture (no broker needed)
# in another shell:
curl localhost:8080/api/fleet | head

make web-install  # npm ci (project-local @angular/cli, no global install)
make web-build    # production SPA bundle into frontend/dist/console
make web-serve    # dev server, proxies /api to the backend  (cd frontend && npm start)

make test         # Go tests with the race detector
make web-test     # Angular unit tests (headless Chrome)
make tf-validate  # terraform validate on the SLO/deploy module
make bench        # the fleet-summary read-path benchmark
make profile      # regenerate the committed before/after profiling artifacts
```

Live telemetry over a broker, end to end:

```bash
make compose-up   # Redpanda + backend (live consumer) + a producer streaming the fixture
open http://localhost:8080/api/fleet
```

## API

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | liveness/readiness probe |
| GET | `/api/fleet` | per-satellite rollup (the optimized hot path) |
| GET | `/api/satellites/{id}/window?n=` | recent telemetry frames for one satellite |
| GET | `/api/incidents?open=true&limit=` | incident feed |
| POST | `/api/incidents/{id}/resolve` | acknowledge an incident |

## Metrics

Real numbers, regenerated by `make profile` (see [docs/profiling.md](docs/profiling.md)).
Measured on an Apple M2 Pro; relative improvements are the point and reproduce on
other hardware.

### Backend hot path: `GET /api/fleet` (rescan vs maintained index)

| Implementation | Time/op | Bytes/op | Allocs/op |
|---|---|---|---|
| Naive (rescan + re-derive every request) | 594.5 µs | 196.8 KiB | 8510 |
| Indexed (maintained rollup) | 344.9 ns | 520 B | 4 |
| **Improvement** | **~1720x faster** | **~388x less** | **~2100x fewer** |

A test (`TestFleetSummaryMatchesNaive`) asserts both implementations return
identical output, so the speedup is not bought with wrong answers.

### Frontend production bundle (zoneless change detection)

| Build | Initial total (raw) | Initial total (transfer) |
|---|---|---|
| Before (zone.js polyfill) | 196.99 kB | 58.60 kB |
| After (zoneless, signals + OnPush) | 162.37 kB | 47.29 kB |
| **Saving** | **34.62 kB (17.6%)** | **11.31 kB (19.3%)** |

## What is real vs simulated

- **Real:** the Go HTTP/JSON API, the concurrency-safe store with maintained
  indexes, incident derivation and resolve, the `franz-go` broker consumer and
  producer, the Angular SPA, and every number in the metrics table (measured, not
  written by hand). `terraform validate` and `terraform fmt -check` pass clean.
- **Simulated telemetry:** there is no physical constellation. Frames come from a
  seeded synthesiser; a few satellites are steered into fault regimes so the
  incident feed is non-empty. The labels are illustrative, not spacecraft ground
  truth. The detector is rule-based thresholds, deliberately legible, not a trained
  model (that lives in the sibling `groundstation`).
- **CI-only:** the **Bazel** build (`bazelisk` in `.github/workflows/bazel.yml`).
  Bazel is not installed in the local dev environment, so the local build path is
  `go build/test` and `npm ci && npm run build`; the Bazel and Go paths compile the
  same packages.
- **Validated, not applied:** the Terraform (Kubernetes Deployment/Service + Grafana
  SLO dashboard and alert rules) is validated, not stood up. Like the sibling
  `liftoff`, there is no live cloud, no live Grafana, and no cloud spend here.

Full breakdown in [docs/assumptions.md](docs/assumptions.md).

## Part of a larger system

`groundstation-console` is the operator surface of a ground-system suite. It reads
the telemetry plane produced by `constellation`, surfaces the diagnoses the
`groundstation` agent graph reasons over (and shares its anomaly taxonomy and
severity thresholds), and is deployed by `liftoff`. The authenticated command path
is owned by `aegis`. Each project stands alone and runs on its own.
